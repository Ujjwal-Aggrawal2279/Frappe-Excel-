# Toolbar Buttons Reference

## Home Tab

| Button | Action |
|---|---|
| Save | Save all pending changes to Frappe |
| Refresh | Reload data from Frappe (discards unsaved changes) |
| Add Row | Append a new blank row |
| Delete Row | Delete selected row(s) |
| Bold | Toggle bold on selected cells |
| Italic | Toggle italic on selected cells |
| Underline | Toggle underline |
| Align Left | Left-align text |
| Align Center | Center-align text |
| Align Right | Right-align text |
| Background Color | Open color picker for cell fill |
| Text Color | Open color picker for font color |
| Number Format | Open number format dropdown |
| Borders | Open border style dropdown |
| Clear Format | Remove all formatting from selected cells |

## View Tab

| Button | Action |
|---|---|
| Focus Cell | Toggle crosshair highlight on active row/column |
| Focus Color | Color picker for crosshair color |
| Hide Rows | Hide selected rows |
| Show All Rows | Unhide all hidden rows |
| Formula Precedents | Toggle green outline on formula source cells |
| Freeze Columns | Set number of frozen (pinned) left columns |
| Meta Column | Toggle _meta (modified time) column |
| Activity Column | Toggle _social (like/comment/assign) column |

## Data Tab

| Button | Action |
|---|---|
| Choose Columns | Open field picker modal |
| Smart Lookup | Open Smart Lookup sidebar |
| Filter | Open filter builder dialog |
| Sort | Open sort dialog |
| Refresh | Reload data (same as Home → Refresh) |
| Import | Open import dialog |
| Export | Export submenu (XLSX / CSV) |

## Insert Tab

| Button | Action |
|---|---|
| Insert Chart | Open chart builder |
| Insert Pivot | Open pivot builder for current sheet |
| New Sheet | Add sheet (blank / DocType / report / query) |
| Sparkline | Insert sparkline in selected cell |

## Format Tab

| Button | Action |
|---|---|
| Conditional Formatting | Open CF rules dialog |
| Borders | Open border editor |
| Number Format | Open number format dialog |
| Clear Format | Remove all formatting from selected cells |
