# Keyboard Shortcuts

## Navigation

| Shortcut | Action |
|---|---|
| Arrow keys | Move one cell in direction |
| Ctrl + Arrow | Jump to last non-empty cell in direction |
| Ctrl + Home | Jump to A1 |
| Ctrl + End | Jump to last used cell |
| Page Up / Page Down | Scroll up/down one page |
| Tab | Move right |
| Shift + Tab | Move left |
| Enter | Move down |
| Shift + Enter | Move up |

## Selection

| Shortcut | Action |
|---|---|
| Shift + Arrow | Extend selection |
| Ctrl + Shift + Arrow | Extend selection to last non-empty cell |
| Ctrl + A | Select all |
| Ctrl + Shift + End | Select to last used cell |
| Click row number | Select entire row |
| Shift + click row number | Range-select rows |
| Click column header | Select entire column |

## Editing

| Shortcut | Action |
|---|---|
| Enter or F2 | Begin editing selected cell |
| Escape | Cancel edit |
| Delete | Clear cell content |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |
| Ctrl + C | Copy |
| Ctrl + X | Cut |
| Ctrl + V | Paste |
| Ctrl + D | Fill down |
| Ctrl + R | Fill right |
| Ctrl + E | Flash Fill |
| F4 | Repeat last action |

## Saving & Loading

| Shortcut | Action |
|---|---|
| Ctrl + S | Save all pending changes to Frappe |
| Ctrl + Shift + R | Refresh — reload data from Frappe |

## Column & Row

| Shortcut | Action |
|---|---|
| Ctrl + Shift + C | Open column picker (Choose Columns) |
| Ctrl + Shift + F | Open filter builder |

## Find & Replace

| Shortcut | Action |
|---|---|
| Ctrl + F | Open Find bar |
| Ctrl + H | Open Find & Replace |
| F3 | Next match |
| Shift + F3 | Previous match |
| Escape | Close find bar |

## Formatting

| Shortcut | Action |
|---|---|
| Ctrl + B | Bold |
| Ctrl + I | Italic |
| Ctrl + U | Underline |

## View

| Shortcut | Action |
|---|---|
| Ctrl + Shift + K | Toggle collaboration sidebar |
| Ctrl + Shift + W | Open workbook panel |

## Rich Text Editor (when RTE modal is open)

| Shortcut | Action |
|---|---|
| Ctrl + S | Save and close modal |
| Escape | Close modal without saving |
| Ctrl + B | Bold |
| Ctrl + I | Italic |
| Ctrl + U | Underline |
| Ctrl + K | Insert link |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |
