# Bold, Italic & Alignment

## Text Style

| Action | Toolbar | Shortcut |
|---|---|---|
| Bold | Home → **B** | Ctrl+B |
| Italic | Home → **I** | Ctrl+I |
| Underline | Home → **U** | Ctrl+U |

Select cells first, then apply. Clicking the same button again toggles it off.

## Alignment

| Alignment | Toolbar | Shortcut |
|---|---|---|
| Align Left | Home → Left align icon | Ctrl+L |
| Align Center | Home → Center icon | Ctrl+E |
| Align Right | Home → Right align icon | Ctrl+R |

## Vertical Alignment

Right-click selected cells → **Format Cells** → Vertical alignment: Top / Middle / Bottom.

## Wrap Text

By default, long text is clipped to the cell width. To wrap text onto multiple lines:

Right-click → **Format Cells** → enable **Wrap Text**.

The row height automatically expands to fit the wrapped content.

## Repeat Last Action

After applying bold/italic/alignment, navigate to another cell and press **F4** to repeat the same format. See [Repeat Last Action](/docs/formatting/repeat-last-action).
