# Borders

Apply borders to cells or ranges to visually organize your data.

## Applying Borders

1. Select the cells or range
2. Home tab → **Borders** button (or Format tab → Borders)
3. Choose a border style from the dropdown:

| Option | Effect |
|---|---|
| All Borders | Border on every edge of every cell |
| Outside Borders | Border only around the outer edge of the selection |
| Thick Box Border | Thick outer border |
| Bottom Border | Only the bottom edge |
| Top and Bottom Border | Top and bottom edges only |
| No Border | Remove all borders |

## Custom Border (Advanced)

Click **More Borders…** in the dropdown to open the border editor:
- Choose **line style** (solid, dashed, dotted, double)
- Choose **line color**
- Click edges in the preview diagram to apply

## Persistence

Border styles are stored in `format_store` and persist in user settings and workbooks.
