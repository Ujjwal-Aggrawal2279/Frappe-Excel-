# Freeze Columns

Frozen columns stay visible on the left side of the grid as you scroll right. This is useful when you want to always see the document Name or Customer while reviewing other columns further right.

## Freezing

1. Click the **View** tab in the toolbar
2. Click **Freeze Columns**
3. Enter the number of columns to freeze (e.g., `2` freezes the Name and Customer columns)
4. Click **Apply**

The frozen columns get a **thicker right border** to visually separate them from the scrollable area.

## Unfreezing

View → Freeze Columns → set to `0` → Apply.

## Tips

- The **Name (ID) column** is always the first column (column A). If you freeze 1 column, you keep the ID visible.
- Freeze 2 columns to keep both the ID and the first major field (e.g., Customer Name) visible.
- Frozen columns are saved per DocType per user in your user settings.
