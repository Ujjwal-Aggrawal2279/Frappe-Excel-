# Reordering Columns

## Drag to Reorder

Click and hold a **column header**, then drag it left or right. A blue indicator line shows the drop position. Release to drop.

The new order is saved automatically to your user settings.

## Via Column Picker

Open the Column Picker (Ctrl+Shift+C). In the right panel, drag fields up/down to reorder them. Click Apply.

## Restrictions

- The **Name (ID)** column is always first and cannot be moved
- Virtual columns (_meta, _social) are always last and cannot be reordered

## Persistence

Column order is stored in user settings per DocType per user.
