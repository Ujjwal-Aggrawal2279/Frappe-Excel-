# Resizing Columns

## Manual Resize

Drag the **right edge of a column header** left or right. The cursor changes to a resize cursor.

## Auto-Fit

Double-click the right edge of a column header to auto-fit the column width to its content.

## Set Exact Width

Right-click a column header → **Column Width** → enter pixels → OK.

## Reset to Default

Right-click a column header → **Reset Width**.

## Row Height

Drag the **bottom edge of a row number** to resize the row height. Auto-fit: double-click the bottom edge.

## Persistence

Column widths and row heights are stored in user settings and workbooks. They persist across sessions.
