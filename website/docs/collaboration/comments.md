# Comments

Add comments to individual records directly from the grid — no need to open the form.

## From the Activity Column

1. Enable the **Activity Column** (View tab → Activity Column)
2. Click the **comment icon** in any row's activity cell
3. A dialog opens
4. Type your comment
5. Click **Add**

The comment is saved as a Frappe `Comment` document linked to the record. It appears in the record's form view timeline.

## From the Context Menu

Right-click any row → **Add Comment**.

## Viewing Existing Comments

Click the comment icon to see the existing comment count badge. To read all comments, click the ID link to open the full form view — comments appear in the timeline at the bottom.

## Mentions

You can `@mention` any Frappe user in your comment. They receive a notification in Frappe.
